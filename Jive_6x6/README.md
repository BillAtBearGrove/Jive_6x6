Controls for 6 motor 6x6 wheelchair.
Converting Invacare TDX SP2 to 6 wheel drive offroad machine.

2026-10-25
Getting Started: Copy project from MyWildThing and converted to new motor controller

# Pololu G2 High Power Dual Motor Driver
This project uses [Dual G2 High Power Motor Driver Shield 24v18](https://www.pololu.com/catalog/product/2518) and drivers must be installed to Arduino IDE
If you are using version 1.8.5 or later of the
[Arduino software (IDE)](https://www.arduino.cc/en/Main/Software), you can use
the Library Manager to install this library:

1. In the Arduino IDE, open the "Sketch" menu, select "Include Library", then
   "Manage Libraries...".
2. Search for "DualG2HighPowerMotorShield".
3. Click the DualG2HighPowerMotorShield entry in the list.
4. Click "Install".
